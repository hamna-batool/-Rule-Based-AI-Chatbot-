# DecodeLabs Project 1: Rule-Based AI Chatbot

## 📌 Project Description

This project is a simple **Rule-Based AI Chatbot** developed using **Python basics**. The chatbot responds to user input based on predefined rules and conditions using **if-elif-else statements**. It is designed as **DecodeLabs Project 1** to demonstrate foundational programming concepts such as variables, strings, input/output, loops, control flow, and decision-making logic.

The chatbot follows a rule-based approach where specific user messages trigger specific responses. This helps understand how basic AI-like conversation systems can be built using simple programming logic.

---

## 🎯 Project Objective

The main objective of this project is to create an interactive chatbot that can:

- Accept user input
- Process the input using conditional statements
- Generate appropriate responses
- Continue the conversation using a while loop
- Stop when the user enters an exit command such as `bye`, `quit`, or `exit`

---

## 🤖 What is a Rule-Based AI Chatbot?

A **Rule-Based AI Chatbot** is a chatbot that works using predefined rules and conditions. Instead of using machine learning or natural language processing, the bot matches the user input with existing conditions and responds accordingly.

For example:

- If the user says `hello`, the bot responds with a greeting.
- If the user asks `how are you`, the bot gives a fixed response.
- If the user says `bye`, the bot ends the conversation.

This project uses Python `if`, `elif`, and `else` statements to implement this rule-based behavior.
